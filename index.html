Cấu hình Lưu trữ Đám mây Supabase

Giúp người khác bấm vào link web luôn nhìn thấy những gì bạn đã đăng lên

Bước 1: Tạo bảng trong Supabase SQL Editor (Chỉ làm 1 lần)

Vào dự án Supabase của bạn → mở mục SQL Editor → nhấn nút Copy lệnh SQL khởi tạo bảng ở trên rồi dán vào và bấm Run.

Mẹo cực hay khi đưa web lên mạng (GitHub Pages / Vercel / Netlify):

Sau khi nhấn "Lưu & Đẩy dữ liệu lên Supabase", bạn bấm thêm nút "Xuất file index.html" trên thanh Admin rồi up file đó lên host. Cấu hình Supabase sẽ được nhúng sẵn vào file, từ đó về sau bạn chỉ cần mở web nhập PIN `01020304` và thêm/sửa thành tích là mọi người vào link thấy ngay lập tức!

Chia sẻ Hồ sơ & Đồng bộ Supabase

2 cách để người khác bấm vào link thấy ngay thành tích bạn đăng lên

Cách 1: Đồng bộ tự động qua Supabase Cloud (Khuyên dùng)

Mở khóa Quản trị (Mã PIN: 01020304) → Bấm nút "Kết nối Supabase Cloud" để nhập URL và Anon Key. Mỗi khi bạn thêm/sửa thành tích trên web, dữ liệu sẽ được lưu trực tiếp lên Supabase để bất kỳ ai truy cập link cũng nhìn thấy ngay tức thì!

Cách 2: Xuất file index.html đã nhúng cứng dữ liệu & cấu hình Cloud

Bấm nút bên dưới để tải về file index.html đã nhúng sẵn toàn bộ thành tích hiện tại + cấu hình Supabase của bạn và tự động khóa ở Chế độ Khách (Chỉ xem) để đẩy lên GitHub Pages, Vercel hoặc Netlify.
