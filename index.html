Chia sẻ Hồ sơ & Bảo vệ Dữ liệu

Giải pháp triệt để giúp người xem thấy đủ thành tích và không thể sửa xóa

1. Chế độ Khách (Viewer Mode) mặc định

Mọi người khi mở trang đều ở Chế độ Khách (Chỉ xem). Toàn bộ nút Thêm/Sửa/Xóa đã được khóa bằng mã PIN của bạn (mặc định: 2026).

2. Xuất file index.html đã nhúng cứng thành tích (Khuyên dùng khi gửi file / đưa lên Hosting)

Vì LocalStorage chỉ lưu trên máy của bạn, sau khi thêm thành tích xong ở chế độ Admin, hãy bấm nút "Xuất file index.html (Đã nhúng dữ liệu)". Hệ thống sẽ tạo ra một file index.html mới chứa sẵn toàn bộ ảnh, ghi chú và thành tích của bạn bên trong code! Bạn gửi file đó hoặc đưa lên GitHub Pages / Vercel thì bất kỳ ai bấm vào link cũng xem được ngay.
